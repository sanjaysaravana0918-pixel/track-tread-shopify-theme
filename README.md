# Track & Tread – Shopify Theme

A custom Shopify storefront developed as part of the Shopify Developer Assignment for Track & Tread.

## Project Overview

Track & Tread is a modern, responsive Shopify storefront focused on outdoor and lifestyle products. The theme was developed using Shopify Liquid with custom sections and responsive layouts for desktop and mobile devices.

## Features

- Custom Shopify theme development
- Fully responsive desktop and mobile design
- Custom hero section
- Announcement / marquee section
- Featured products section
- Curated drops section
- Brand story section
- Category mosaic
- Recommended products
- Journal / stories section
- Benefits section
- Customer testimonials
- Social gallery
- Community CTA
- Newsletter section
- Custom header and footer
- Shopify Theme Editor compatible sections

## Technology Used

- Shopify Liquid
- HTML5
- CSS3
- JavaScript
- Shopify Theme Architecture
- Git & GitHub

## Theme Structure

- `assets/` – CSS, JavaScript and theme assets
- `blocks/` – Reusable Shopify theme blocks
- `config/` – Theme configuration and settings
- `layout/` – Main Shopify theme layouts
- `locales/` – Translation and localization files
- `sections/` – Custom storefront sections
- `snippets/` – Reusable Liquid components
- `templates/` – Shopify page templates

## Development Workflow

The theme is connected directly to this GitHub repository through Shopify's GitHub integration.
